Android build route:
1. Upload this whole project to a GitHub repository.
2. Open Actions -> Build Mindustry Mod.
3. Run workflow if it did not start automatically.
4. Open the completed run and download the OrangeSupport1597 artifact.
5. Unzip the artifact to get OrangeSupport1597.jar.
6. In Mindustry v8 Build 159.7, open Mods -> Import Mod and select the JAR.
7. Restart Mindustry if requested.

The official Java mod template documents JDK 17 and cross-platform Android-compatible JAR builds.
